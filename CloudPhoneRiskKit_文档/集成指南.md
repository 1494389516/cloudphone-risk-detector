# CloudPhoneRiskKit 集成指南

## 1. 快速开始

### 1.1 安装

将 CloudPhoneRiskKit 模块添加到 Xcode 项目中：

```swift
// Package.swift
dependencies: [
    .package(path: "../RiskDetectorApp")
]
```

### 1.2 最简集成

```swift
import CloudPhoneRiskKit

// 启动 SDK（建议在 AppDelegate.didFinishLaunching 中调用）
CPRiskKit.shared.start()

// 同步评估（适合后台线程）
let report = CPRiskKit.shared.evaluate()
print("Risk Level: \(report.riskLevel)")
print("Score: \(report.score)")

// 停止 SDK
CPRiskKit.shared.stop()
```

### 1.3 推荐集成（async/await）

```swift
import CloudPhoneRiskKit

// iOS 13+
let report = await CPRiskKit.shared.evaluateAsync()

// 或使用 Actor-isolated 入口（推荐）
let report = await RiskEvaluationActor.shared.evaluate(
    config: .default,
    scenario: .payment
)
```

## 2. 配置

### 2.1 基础配置

```swift
let config = CPRiskConfig(
    enableBehaviorDetect: true,    // 行为检测（触摸/运动）
    enableNetworkSignals: true,     // 网络信号
    enableAntiTamper: true,         // 反篡改检测
    enableTemporalAnalysis: true,   // 时序分析
    threshold: 30                   // 风险阈值
)

let report = CPRiskKit.shared.evaluate(config: config)
```

### 2.2 场景化评估

不同业务场景使用不同的风险阈值和检测策略：

```swift
// 登录场景
let loginReport = CPRiskKit.shared.evaluate(
    config: .default,
    scenario: .login
)

// 支付场景（更严格）
let paymentReport = CPRiskKit.shared.evaluate(
    config: .default,
    scenario: .payment
)

// 自定义场景
let customScenario = RiskScenario(rawValue: "high_value_transfer")
let report = CPRiskKit.shared.evaluate(
    config: config,
    scenario: customScenario
)
```

### 2.3 远程配置

```swift
// 设置远程配置端点
CPRiskKit.shared.configureRemoteConfig(
    endpoint: URL(string: "https://api.example.com/risk/config")!
)

// 手动更新远程配置
try await CPRiskKit.shared.updateRemoteConfigAsync()

// killSwitch 安全：防止远程配置劫持
RiskDetectionEngine.localKillSwitchOverride = true
```

## 3. 评估结果处理

### 3.1 RiskVerdict 判决

```swift
let report = CPRiskKit.shared.evaluate()

switch report.verdict.action {
case .allow:
    // 正常放行
    proceedWithTransaction()

case .challenge:
    // 需要验证码/滑块
    showCaptchaChallenge()

case .stepUpAuth:
    // 需要短信/人脸验证
    requestSMSVerification()

case .block:
    // 拒绝操作
    blockTransaction()
}
```

### 3.2 风险报告字段

```swift
let report = CPRiskKit.shared.evaluate()

// 基础信息
report.score           // 风险分数 (0-100)
report.riskLevel       // 风险等级
report.verdict         // 判决结果

// 检测详情
report.detectedMethods // 命中的检测方法列表
report.isJailbroken    // 是否越狱
report.details         // 详细信息字符串
```

## 4. 自定义扩展

### 4.1 自定义 Signal Provider

```swift
public final class MyCustomProvider: RiskSignalProvider {
    public static let shared = MyCustomProvider()

    public let id = "my_custom_provider"

    public func signals(snapshot: RiskSnapshot) -> [RiskSignal] {
        var signals: [RiskSignal] = []

        // 自定义检测逻辑
        if detectSomething() {
            signals.append(RiskSignal(
                id: "my_custom_signal",
                score: 30,
                confidence: 0.8,
                state: .hard(detected: true),
                layer: 3,
                weightHint: 60
            ))
        }

        return signals
    }
}

// 注册（必须在 start() 之前）
CPRiskKit.shared.register(provider: MyCustomProvider.shared)
CPRiskKit.shared.start()
```

### 4.2 自定义 Detector

```swift
struct MyDetector: Detector {
    func detect() throws -> DetectorResult {
        var score: Double = 0
        var methods: [String] = []

        // 检测逻辑
        if suspiciousCondition {
            score += 25
            methods.append("custom:suspicious_condition")
        }

        return DetectorResult(score: min(score, 90), methods: methods)
    }
}

// 注册
DetectorRegistry.shared.register(type: .hook, factory: { MyDetector() })
```

### 4.3 自定义日志输出

```swift
// 实现 LogDestination 协议
struct FileLogDestination: LogDestination {
    let fileURL: URL

    func write(_ entry: LogEntry) {
        let line = "[\(entry.level.label)] \(entry.message)\n"
        if let data = line.data(using: .utf8) {
            try? data.append(to: fileURL)
        }
    }
}

// 注册
Logger.addDestination(FileLogDestination(fileURL: logFileURL))

// Release 模式启用日志（仅 warn/error/critical）
Logger.releaseLoggingEnabled = true
```

## 5. 线程安全

### 5.1 同步 API

`evaluate()` 是线程安全的，可以在任何线程调用。内部通过 NSLock 保护可变状态。

```swift
// 可以在后台线程安全调用
DispatchQueue.global().async {
    let report = CPRiskKit.shared.evaluate()
}
```

### 5.2 异步 API（推荐）

```swift
// async/await（推荐）
let report = await CPRiskKit.shared.evaluateAsync()

// Actor-isolated（最安全）
let report = await RiskEvaluationActor.shared.evaluate()
```

### 5.3 回调 API（已废弃）

```swift
// ⚠️ 已废弃，建议迁移到 async/await
CPRiskKit.shared.evaluateAsync { report in
    // completion 在主线程回调
    updateUI(with: report)
}
```

## 7. 安全最佳实践

### 7.1 启动时机

```swift
// ✅ 推荐：App 启动时立即调用
func application(_ application: UIApplication,
                 didFinishLaunchingWithOptions launchOptions: ...) -> Bool {
    CPRiskKit.shared.start()
    return true
}

// ❌ 避免：延迟启动给攻击者注入窗口
DispatchQueue.main.asyncAfter(deadline: .now() + 5) {
    CPRiskKit.shared.start() // 太晚了！
}
```

### 7.2 killSwitch 保护

```swift
// 防止远程配置被劫持后关闭所有防护
RiskDetectionEngine.localKillSwitchOverride = true
```

### 7.3 服务端验签

```swift
// 构建安全上报信封
let envelope = try await CPRiskKit.shared.buildSecureEnvelopePayload(...)
// 服务端必须验证信封签名，拒绝无效签名的报告
```

## 8. 常见问题

### Q: SDK 评估耗时多长？

评估时间通常在 50-200ms，取决于启用的检测器数量和设备性能。使用 `evaluateAsync()` 可避免阻塞主线程。

### Q: 模拟器上能正常工作吗？

大部分反篡改检测器在模拟器上返回空结果（`DetectorResult.empty`），这是设计行为。越狱检测和硬件指纹在模拟器上的结果不具参考价值。

### Q: 如何处理误报？

1. 调整场景化阈值（`RiskScenario`）
2. 使用 `config.threshold` 自定义阈值
3. 检查审计日志定位触发的检测器
4. 通过远程配置动态调整权重

### Q: 支持 ObjC 调用吗？

是的，`CPRiskKit` 继承自 `NSObject` 并提供 `@objc` 标注的 API：

```objc
CPRiskReport *report = [[CPRiskKit shared] evaluate];
CPRiskReport *report = [[CPRiskKit shared] evaluateWithConfig:config];
```

### Q: 如何测试 SDK 集成？

利用 `DetectorRegistering` 协议注入 Mock：

```swift
class MockDetectorRegistry: DetectorRegistering {
    var stubbedResult: DetectorResult = DetectorResult(score: 50, methods: ["test:mock"])

    func detect(type: DetectorRegistry.DetectorType) -> DetectorResult {
        stubbedResult
    }
    // ... 实现其他协议方法
}
```

## 9. API 迁移指南

### 从 1.0 迁移到 2.0

| 1.0 API | 2.0 API | 说明 |
|---------|---------|------|
| `evaluate()` | `evaluate(config:scenario:)` | 增加场景化支持 |
| `evaluateAsync(completion:)` | `evaluateAsync() async` | 迁移到 async/await |
| `JailbreakEngine.detect()` | `DetectorRegistry.shared.detectAll()` | 统一检测器架构 |
| 无 | `RiskEvaluationActor.shared.evaluate()` | Actor-isolated 入口 |
| 无 | `Logger.audit()` | 审计追踪 |
| 无 | `Logger.addDestination()` | 自定义日志输出 |
